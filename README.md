# Peneiras On

Plataforma que descentraliza a captação de talentos no futebol brasileiro: organiza
inscrição, alocação geográfica e ranking pelo olheiro. Projeto acadêmico da FIAP
(1º ano de Engenharia de Software), em parceria com a Pelé Academia.
