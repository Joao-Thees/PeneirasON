# Justificativa de imitação:

1° -> O Visual MVP usa query string para buscar informações que o usuário desejasse visualizaar/interagir
2° -> Seguindo essa lógica, faz mais sentido implementar inputs que serão validados "imitando" a lógica da query string. Por esse motivo, não optamos pela utilização de números como: "insira [1] para isso ou [2] para aquilo".
